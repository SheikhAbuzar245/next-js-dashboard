We are developing a next-generation gym management platform in partnership with our supplier, Sahar Hajj Hassan. This project focuses on leveraging cutting-edge AI Voice Agents to automate inbound leads, class bookings, and member motivation. We are looking for a developer to lead the technical integration between our Next.js/Node.js stack and real-time voice infrastructure.
Key Responsibilities:
Voice Integration: Develop and deploy AI voice agents capable of natural, low-latency conversations with gym members.
Backend Logic: Build robust API routes in Node.js to sync voice agent actions (like booking a class) with our database.
Frontend Dashboard: Create a high-performance Next.js dashboard for gym owners to monitor agent performance and member data.
Tool Calling: Connect the AI (e.g., GPT-4o, Claude, or ElevenLabs) to external tools like Google Calendar, Stripe, or gym CRMs (GoHighLevel/Trainerize).
Technical Requirements:
Frameworks: Mastery of Next.js (App Router) and Node.js/TypeScript.
AI/Voice: Experience with Voice APIs (e.g., Vapi, Retell AI, Bland AI, or Hume).
Real-time: Strong understanding of WebSockets or WebRTC for low-latency audio streaming.
Database: Experience with PostgreSQL/Prisma or Firebase for real-time data syncing.
